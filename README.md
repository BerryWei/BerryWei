# Ting-Ju (Berry) Wei — personal website

Static site served by GitHub Pages at https://berrywei.github.io/BerryWei/

- `index.html` — all content (edit text, publications, news here)
- `css/style.css` — design tokens (light/dark) and layout
- `js/main.js` — theme toggle, nav, tabs, video autoplay, generative DMN hero canvas
- `media/` — figures (WebP) and looping videos (MP4) converted from paper figures
- `docs/Berry_Wei_CV.pdf` — CV

No build step. Preview locally with `python3 -m http.server` and open http://localhost:8000.
